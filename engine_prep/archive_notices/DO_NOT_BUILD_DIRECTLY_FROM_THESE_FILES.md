# DO NOT BUILD DIRECTLY FROM THESE FILES

This archive holds the original engine, data and research files — **Files 1–8 and the Addition to File 6** — exactly as they were, for traceability only.

**They are not a build source.** Parts of them were replaced by later approved decisions, and they contradict the current design in places. Build from:

1. **File 9 v4 Master Specification** — platform behavior, screens, brokers, leverage and margin, risk controls, Phase 0, security.
2. **Engine_v4_Current_Requirements** — the current engine and strategy architecture; every requirement carries a tag showing which file and section it came from.

If the Master and the engine document ever conflict, that is an error to bring to Jonathan. The coder does not settle it, and never settles it by going back to these files.

Do not copy from these files into code, tests or configuration. If something seems to be missing from Engine_v4_Current_Requirements, ask — its traceability appendix shows where every section of every file here ended up.
