Windows map — where everything lives (v4, updates File 9 v3 Figure 9)

The main window never closes and holds only what you need to act in seconds; anything you read gets its own window, one click away in Windows ▾ (7 windows). Every separate window has the same thin top bar (← MAIN WINDOW / F2, PAPER/LIVE, AUTO + STOP AUTO, clock, blink chips, Day P&L, health, Windows ▾, FLATTEN ALL) and the 22 px alert line. A planning map, not a window of the platform. Section numbers refer to the decision log; drawing IDs refer to the mockups folder.
