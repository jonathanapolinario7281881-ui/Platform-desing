# Engine source archive — reference only, not a build source

Files 1–8 and the Addition to File 6 — the original engine, data and research files — are kept in a separate archive, **`Engine_Source_Archive_REFERENCE_ONLY.zip`**, outside this coding package.

- They exist for traceability only: every still-valid requirement in them has been carried into **Engine_v4_Current_Requirements**, with its source tag, and the traceability appendix there shows where each section of each file ended up.
- **Do not build directly from these files.** Parts of them were replaced by later approved decisions (for example IBKR as the order broker, and margin leverage above 1×).
- Build from the File 9 v4 Master Specification and Engine_v4_Current_Requirements, in the source order of Master section 1.3.
